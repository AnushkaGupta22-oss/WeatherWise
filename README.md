# 🌦️ WeatherWise – Daily Weather Application

WeatherWise is a simple full-stack weather application that allows users to search for a city and view its current weather conditions along with today's maximum and minimum temperatures.

## ✨ Features

- Search weather by city name
- Display current temperature
- Show today's maximum and minimum temperatures
- Display weather conditions with dynamic icons
- Show feels-like temperature
- Display humidity and wind speed
- Loading and error handling
- Responsive user interface

## 🛠️ Tech Stack

**Frontend**
- React.js
- Vite
- CSS

**Backend**
- Node.js
- Express.js

**API**
- Open-Meteo Weather API
- Open-Meteo Geocoding API

## 🚀 Getting Started

1. Clone this repository.
2. Install dependencies in both frontend and backend folders.
3. Start the backend server.
4. Start the Vite frontend development server.
5. Open the local frontend URL in your browser.
